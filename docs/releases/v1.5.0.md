# v1.5.0

Released 2026-07-26.

Enterprise auditable-vault release: deterministic-first operation, edge lineage, a graph query surface, and the outcome-memory loop.

## Added

- **Pluggable LLM backends** (`LLM_BACKEND` / `CORTEX_LLM_BACKEND`): `openai-compatible` (OpenRouter, Azure OpenAI, Ollama, vLLM — default), `bedrock` (AWS credential chain, lazy `boto3`), or `none`. All compiler LLM usage routes through the new `cortex/llm/backend.py` abstraction.
- **Zero-LLM (deterministic-first) mode**: `LLM_BACKEND=none` guarantees no LLM client is constructed and no model call is made — ingest (MarkItDown), the knowledge graph (wikilinks, tags, `derived_from`), and QMD search all work without a key. `start.sh` no longer requires an API key for `none`/`bedrock`. Pinned by contract tests (`tests/test_zero_llm_contract.py`).
- **Edge lineage**: every graph edge carries an `origin` label — `extracted` (deterministic structure extraction), `manual` (created via `vault_link` or REST), with `inferred` reserved for LLM cross-references.
- **`vault_trace`** (MCP + `GET /api/v1/trace/{path}`): full lineage of a note — provenance (author, model, timestamps), raw sources via `derived_from`, and all labeled edges. Answers "why does the vault say X" back to the source document.
- **Graph query surface**:
  - `vault_path` / `GET /api/v1/graph/path` — shortest paths between two notes ("what connects this policy to the procedures that implement it"). Tag hubs are excluded from traversal; every hop reports edge type and origin.
  - `vault_impact` / `GET /api/v1/graph/impact` — transitive upstream dependents of a note, for change-impact analysis ("when this regulation note changes, what needs review").
  - `vault_explain` / `GET /api/v1/explain/{path}` — entity summary with provenance, sources, links in/out, and contradictions.
- **Usage counters**: MCP and REST note reads increment per-note read counters in `.cortex/usage.json`.
- **Feedback outcomes**: `vault_feedback` and `POST /api/v1/feedbacks` accept an optional `outcome` label (`useful` / `dead-end` / `corrected`) recording whether retrieved knowledge held up.
- **Curation report** (`GET /api/v1/curation/report?stale_days=90`): most-read, never-read, stale, and contradicted notes (contradiction edges + corrected feedback) — knowledge quality management built from usage and outcome signals.

## Upgrade notes

- No breaking changes. Existing graphs gain `origin` labels on the next rebuild (edges rebuilt by the watcher or a reindex are stamped automatically); edges created before this release report `origin: unknown` in `vault_trace` until rebuilt.
- `boto3` is not installed by default; `LLM_BACKEND=bedrock` raises a clear error asking for it if missing.
