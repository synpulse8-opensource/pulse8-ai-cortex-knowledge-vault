# OpenFang — Open-Source Agent Operating System

OpenFang is a production-grade, open-source Agent Operating System built entirely in Rust. It treats AI agents as autonomous OS-level processes with spawn, suspend, resume, and reclaim semantics — not as chatbot wrappers.

## Architecture
- 14 Rust crates, 137,728 lines of code, zero Clippy warnings
- Single binary deployment
- Modular kernel design:
  - openfang-kernel: Orchestration, workflows, metering, RBAC, scheduler, budget tracking
  - openfang-runtime: Agent loop, 3 LLM drivers, 53 tools, WASM sandbox, MCP client+server, Google A2A
  - openfang-api: 140+ REST/WS/SSE endpoints, OpenAI-compatible API, dashboard
  - openfang-channels: 40 messaging adapters with rate limiting, DM/group policies
  - openfang-memory: SQLite-based persistent memory

## Performance (v0.1.0 benchmarks, self-reported)
- 180ms cold start (vs 3-6s for Python frameworks)
- 40MB idle memory baseline, ~12MB per additional agent (linear scaling)
- ~13x throughput on routing tasks vs CrewAI/LangGraph
- 32MB install size vs 100MB+ for Python alternatives

## Security (16 layers)
- WASM dual-metered sandbox (fuel + epoch)
- Ed25519 manifest signing
- Merkle hash-chain audit trail
- Taint tracking, SSRF protection, secret zeroization
- HMAC-SHA256 mutual authentication
- GCRA rate limiter, subprocess isolation
- Prompt injection scanner, path traversal prevention
- RBAC: agents declare required tools, kernel enforces
- SHA256-based tool call loop detection with circuit breaker

## Hands (Autonomous Capability Packages)
Pre-built autonomous agents that run on schedules, build knowledge graphs, and report to dashboard:
- Clip: Video-to-shorts pipeline (8 stages)
- Lead: Autonomous lead generation with ICP scoring
- Collector: OSINT-grade monitoring with change detection
- Predictor: Superforecasting with Brier scores
- Researcher: Deep research with CRAAP credibility evaluation
- Twitter: Autonomous X management with approval gates
- Browser: Web automation via Playwright with purchase guardrails
- Custom Hands: Define via HAND.toml, publish to FangHub

## Protocol Support
- Model Context Protocol (MCP): Both client and server
- Google A2A: Agent-to-agent task delegation
- OpenFang Protocol: P2P networking with HMAC-SHA256 mutual auth
- 27 LLM providers supported across 4 performance tiers

## Platform
- Native desktop app via Tauri 2.0 (system tray, notifications, auto-start, global shortcuts)
- Cross-platform: macOS, Linux, Windows
- OpenAI-compatible API layer
